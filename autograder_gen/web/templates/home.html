What is AutograderGen?

A tool for lecturers to edit and generate assessment scripts for Grading a Programming Assignment on Gradescope. It supports filling out an interactive web form or uploading a YAML configuration to edit and generate packaged ZIP files ready to be uploaded to Gradescope.

The diagram below illustrates how a lecturer uses AutograderGen to edit and generate assessment rules, package the autograder, deploy it to Gradescope, and how students' submissions are automatically evaluated in isolation.
